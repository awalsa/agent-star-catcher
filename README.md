Star Catcher — a tiny browser game built by an AI agent from one prompt: catch the falling stars with your basket. 60 seconds, 15 stars wins. Made for make.fun's "The agent builds a game from one prompt" bounty.

## Play it

Open `game/index.html` in any browser — no build, no server. Move with ← → / A D or drag with mouse/touch.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `POST.json` — the address of the X post carrying the video — to `/output/POST.json`, where the bounty gate reads it.
